# Changelog

## 2026-10-07 — Gym PWA release

Modified the supplied Forge training journal into the Gym-branded, installable PWA. The release adds an industrial visual system and matching app icons, a FitQuest-inspired XP/level/streak/milestone display derived only from actual completed sessions and sets, quick logging, local media integrity/offline-cache verification, contributor/deployment documentation, and regression tests. It preserves the repository's existing GNU GPL version 3 license and all third-party notices.
