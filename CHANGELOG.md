# Changelog

## 2026-10-07 — Forge interface release

Rebranded the PWA as Forge across the page, install manifest, icon, navigation and product documentation. Replaced automatic full-form onboarding with a short welcome and plain-language plan flow. Added a guided start choice, removed body measurements from plan setup, explained sets and repetitions beside the logger, and tucked the optional effort rating away. Simplified home priorities and renamed progress labels. Added keyboard, reduced-motion and touch-target refinements while preserving local media, offline support and journal-derived progress.

## 2026-10-07 — Forge clarity pass

Put long plan rationale behind “Why this plan?”, explain sets and reps beside the editable plan, change “owner sync” to “account sync” in the interface, and add regression coverage for the novice flow. The quick-log, saved-progress and data-cleanup paths were smoke-tested in the local preview. Automated tests pass; a five-person beginner study is still a recommendation, not a completed study.

The GitHub repository remains named `Gym`. This modified release preserves its existing GNU GPL version 3 license and all third-party notices.
