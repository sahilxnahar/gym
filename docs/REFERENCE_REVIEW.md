# Reference review

All ten user-linked repositories were reviewed for product ideas, useful assets, reuse permissions and limits. Forge uses the supplied Forge and FitQuest archives, the separately credited MIT exercise-data metadata, and a small, explicitly attributed OpenGym workout-ordering adaptation. It does not indiscriminately merge ten codebases. A public repository is not, by itself, a grant of permission to reuse its assets.

## Product direction

Forge combines a local-first workout journal, searchable movement library, editable plans, set logging, timers, progress and offline-first installability. The guided session, routine and consistency patterns were informed by [DuarteSantos8/openGym](https://github.com/DuarteSantos8/openGym), [InlitX/GymMane](https://github.com/InlitX/GymMane) and [chathushkaimasara/My-Workouts](https://github.com/chathushkaimasara/My-Workouts). FitQuest informed the journal-derived points, levels, streak and milestone layer. The new Tools area adds bodyweight/band training, adult-only BMI screening, simple cardio ideas and local diet reminders without turning measurements into lifting instructions or calorie goals.

The Forge movement library includes English exercise names, attributes and instructions from [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset), which the upstream OpenGym notice identifies as separately MIT-licensed. That permission does not cover Gym Visual/AscendAPI imagery. Forge did not copy those upstream images, GIFs, videos or thumbnails. Its six runtime movement GIFs and matching stills come from the user-supplied Forge archive; the FitQuest preview webp is not shipped as a runtime demo.

## Repository-by-repository assessment

1. [openai/gym](https://github.com/openai/gym) is an archived Python reinforcement-learning toolkit, not a gym exercise app. Its clear state/lifecycle thinking is adjacent inspiration. No source or MuJoCo assets were added.
2. [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset) supplies the movement metadata and written exercise instructions already present in the Forge library. The dataset's MIT notice is preserved separately; excluded images/videos keep their distinct Gym Visual ownership.
3. [InlitX/GymMane](https://github.com/InlitX/GymMane) is an offline Android tracker with a muscle map, routines, rest timers and progress. Its code has GPL-3.0-only terms plus an additional attribution condition; its credited art is CC BY-SA 4.0. No code or art was reused.
4. [chathushkaimasara/My-Workouts](https://github.com/chathushkaimasara/My-Workouts) is a Flutter routine and workout tracker with local persistence, charts and backup/restore. Its code is MIT-licensed; packaged fonts/assets have their own rights. No source or media was added.
5. [furkankayam/fullstack-gym-iot-app](https://github.com/furkankayam/fullstack-gym-iot-app) is a React/Spring/MQTT/ESP32 membership and check-in system. Its code is MIT-licensed; NFC access, occupancy and gym administration are outside Forge's personal training-journal scope.
6. [xScherpschutter/ActioLift](https://github.com/xScherpschutter/ActioLift) is a Wails/Go/Preact desktop POS and gym-membership manager with SQLite. Its repository carries MIT terms; dependency and asset rights remain separate. No code or assets were copied.
7. [faeztgh/ANDROID-GymApp](https://github.com/faeztgh/ANDROID-GymApp) is a Java Android app for courses, profiles and reviews. No project license was found, so public visibility does not grant reuse rights. No code or assets were copied.
8. [wesleyyan-sb/masscience](https://github.com/wesleyyan-sb/masscience) is a bodyweight/nutrition tracker with trend estimates and local persistence. The repository identifies its work as CC0; dependencies and third-party assets may have separate rights. Its uncertainty-aware progress presentation was a reference; calorie-control features were not added.
9. [Kyrillos-Samy1/Gymo](https://github.com/Kyrillos-Samy1/Gymo) is a React exercise-discovery app with animated previews. Its MIT file conflicts with a README noncommercial restriction and its media rights are unclear. No code, GIF, video, branding or tutorial was copied.
10. [DuarteSantos8/openGym](https://github.com/DuarteSantos8/openGym) is the closest PWA and a self-hosted workout tracker. At commit [`31c6795b40fb54130192b5016d7dc29e9f457d30`](https://github.com/DuarteSantos8/openGym/tree/31c6795b40fb54130192b5016d7dc29e9f457d30), its code is AGPL-3.0. With the user's explicit choice to change the whole Forge project to AGPL-3.0, Forge adapts only the verified adjacent-pair grouping and paired-unit reordering helpers. See [`OPEN_GYM_ATTRIBUTION.md`](../OPEN_GYM_ATTRIBUTION.md) for exact file paths, changes and license. No OpenGym screenshots, animation or disputed exercise media were reused.

## Reuse, license and boundaries

The user selected AGPL-3.0 for the Forge project before OpenGym code was adapted. The former root GPLv3 file was replaced by the complete AGPL v3 text, and the adapted helper is available in the public `sahilxnahar/Gym` source corresponding to the network-served app. Exercise-data metadata retains its independent MIT attribution; this project license does not override separate image/media rights. Forge's band drawing is an original local SVG, and its bodyweight/band demonstrations are not copied from OpenGym.

Membership management, POS, NFC/IoT occupancy, Android-only course screens, reinforcement-learning environments, calorie prescriptions and remote asset hotlinks are outside this release. This is a technical provenance summary, not legal advice; recheck the linked source notices before any future reuse.
