# Forge usability test plan

This is a suggested user study, not a completed test.

## Participants and setup

Recruit five adults who do not regularly strength-train. Use a fresh local browser profile and a phone-sized viewport. Do not enter real medical details or personal measurements. Ask participants to think aloud, but do not coach them through the interface.

## Tasks

1. Choose a goal, equipment and schedule; review and save a starter plan.
2. Start a workout, add a movement, mark a set complete, use the rest timer and finish the workout.
3. Log a workout they have already completed without entering sets.
4. Find the saved workout and export a backup.

## Record

For each task, note completion without help, time to completion, misclicks, abandoned screens and any term the participant cannot explain. Ask which action they expected on Home and whether the on-device data notice made sense.

## Ship criteria

Aim for four of five participants to finish each task without a hint. Fix repeated points of confusion before adding more dashboard metrics. Repeat the test with keyboard-only access and a screen reader. Record actual results before making claims about beginner usability.
