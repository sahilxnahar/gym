# Forge design tokens

| Token | Value | Use |
|---|---|---|
| Warm paper | `#F3F0E8` | App canvas and readable background |
| Panel | `#FFFDF8` | Cards, forms and dialogs |
| Charcoal | `#24231F` | Sidebar, high-priority panels and primary text |
| Ember | `#DF6A47` | Primary action, focus ring and key status |
| Green | `#355E49` | Completed work and positive progress |
| Muted text | `#625F58` | Secondary instructions, with adequate contrast |

Use native system sans-serif for instructions and headings. Use a restrained system monospace only for numeric readouts. Keep labels at a readable size; do not reduce workout instructions to fit decorative layouts. Buttons and form controls have at least 48px height on the phone layout. The stylesheet honors `prefers-reduced-motion` and visible keyboard focus.
